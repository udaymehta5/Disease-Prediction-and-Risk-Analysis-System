Vita Signal ML is a clinical decision-support and disease risk analysis microservice.
It provides FastAPI endpoints for symptom consultation, biomarker OCR report analysis, and adaptive health questionnaires.
Powered by Groq LLM clinical reasoning and pgvector semantic retrieval over medical reference guidelines.
